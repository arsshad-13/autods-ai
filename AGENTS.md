# AutoDS AI

## Project Overview

AutoDS AI is an Autonomous Data Scientist platform.

The application automatically:

- Uploads datasets
- Cleans data
- Detects missing values
- Detects outliers
- Performs feature engineering
- Trains ML models
- Tunes hyperparameters
- Explains models using SHAP
- Generates dashboards
- Creates reports
- Deploys trained models

## Coding Standards

- Add docstrings.
- Prefer async APIs.
- Use environment variables.
